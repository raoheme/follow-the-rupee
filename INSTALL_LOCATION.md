# Canonical installation location
All repository files must reside directly under:

`C:\Projects\Mumbai Civic Lens\mumbai-civic-lens`

Do not create a duplicate nested `mumbai-civic-lens\mumbai-civic-lens`. Extract the ZIP so that `README.md`, `Cargo.toml`, `package.json`, `compose.yaml`, `apps`, `crates`, `openapi` and `scripts` are immediate children of the canonical directory. Paths in contracts are repository-relative and use forward slashes; PowerShell/Windows paths may use backslashes.
