# Non-negotiable guardrails
- All operational IDs start `SYN-DEMO-`; all operational records are `SYNTHETIC_DEMONSTRATION`.
- No official BMC integration, legal jurisdiction, authenticated-evidence, zero-cost DLP, immutable-history or contractor-culpability claim.
- Institution/department/post accountability only; no unsupported personal blame.
- `CLOSURE_CLAIMED_PENDING_VERIFICATION` differs from verified completion; silence never verifies.
- Spatial proximity produces `SPATIALLY_INFERRED_PROVISIONAL`.
- Never silently reject duplicates. Offer endorse, add evidence, or create separate.
- No real PII/OTP/contact data/external street imagery. `.env.local` is never committed or printed.
- GeoJSON is `[longitude, latitude]`; metres use PostGIS geography or verified projection. Money uses integer paise; timestamps use UTC ISO-8601.
